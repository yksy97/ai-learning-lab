AI のしくみを、動かしながら理解する

機械学習のモデルをブラウザ上でその場で学習させ、中で何が起きているかを見るためのアプリです。 学習も推論もすべてブラウザ内の JavaScript で計算していて、外部ライブラリもサーバも使いません。

各モデルには たとえ話ガイド（紙芝居のように順番に見せる）と 詳細（自由にいじれる画面）があります。 はじめてのモデルは、まずガイドから見るのがおすすめです。

このアプリについて

全部ブラウザの中

ニューラルネットの順伝播・逆伝播・Adam、Transformer の注意機構まで手書きしている。学習は目の前で走っているので、設定を変えた結果がそのまま見える。

たとえ話つき

専門用語の前に、まず身近なたとえで全体像をつかむ。ガイドの各ステップには「専門用語では」の対応表がついている。

失敗も見せる

うまくいく例だけでなく、モード崩壊・勾配消失・事後崩壊など、教科書に出てくる失敗をその場で再現できる。

小さく正しく

2次元の点や小さな文書集という小さな題材にして、そのぶん中身を全部見せる。逆伝播は数値微分と一致することをテストで確認している。

すべてブラウザ内の JavaScript で計算（外部ライブラリなし）
