# 文言ガイド

AI Learning Lab の画面に出す文章の決まりごと。新しいページを足すときも、ここに合わせる。

## 読者

**働きながら学び直している大人**（AI の仕事をしていない人も含む）。
中高生にも読めることは目指すが、**子ども向けの語り口にはしない**。「がんばろう！」「すごい！」のような励ましや、達成感の演出は入れない。代わりに、**何ができるようになるかを具体的に示す**ことで前に進んでもらう。

## 語り口

| | |
|---|---|
| 文体 | ですます。断定を避けすぎない（「〜と言えるかもしれません」より「〜です」） |
| 一文 | 60字くらいまで。2つのことを1文に詰めない |
| 人称 | 読者は「あなた」と呼ばない。「〜してください」「〜すると見えます」 |
| 専門用語 | 避けない。ただし**初出で必ず言い換える**（「潜在変数（モデルが内部で使う、絵の設計メモにあたる数）」） |
| たとえ話 | たとえで説明したら、**必ず対応する専門用語を並べて書く**。たとえ話だけで終わらせない |
| 失敗 | 失敗した読者を責める文を書かない。「よくあるつまずきです」と正常化する |
| 誇張 | しない。できないことは「できません」と書く（例：この画面に LLM は入っていません） |

## 禁止

- 「簡単です」「誰でもできます」— できなかった人を責める言い方になる
- 「〜するだけです」— 実際には簡単ではないことが多い
- 感嘆符の多用、絵文字
- 「AI が勝手に学習します」のような、中身をぼかす言い方
- 出典のない数字・順位

## ページの構成

どのページも、この順で並べる。

1. **このページのゴール** — 行動で書く（「〜を説明できる」「〜を見分けられる」「〜を再現できる」）。3つまで
2. **目安の時間** — 正直に。長いときは長いと書く
3. **つまずきやすいところ** — 折りたたみ。先回りして置く
4. 本文（触る → 予想する → 確かめる）
5. **ふりかえり** — 自己説明欄、または学習パスのチェック

ゴールは `public/js/goals.js` に集約してある。ページ側では `mountGoal('<id>')` を呼ぶだけ。

## 用語の表記

同じものを指す言葉は、次の3つ組で統一する。**たとえ → 正式名称（英語）** の順に書き、以降は正式名称を使う。

| たとえ | 日本語 | 英語・記号 |
|---|---|---|
| 偽札職人 | 生成器 | Generator, G |
| 警察 | 識別器 | Discriminator, D |
| サイコロの目 | 潜在変数 | z |
| メモ | 潜在変数 | z（VAE では μ と σ の組） |
| 模写職人 | エンコーダ / デコーダ | Encoder / Decoder |
| 司書 | 検索 | Retriever |
| 作家 | 言語モデル | LLM |
| 罰点 | 損失 | Loss |
| 手がかり・声 | 勾配 | Gradient, ∇ |

表記ゆれの禁止：ニューラルネット／ニューラルネットワーク → **ニューラルネットワーク**。
学習率／ラーニングレート → **学習率**。トークン化／分かち書き → **トークン化**。

## コードの見せ方

教材に出すコードは **Python が主**。

- 左に「実務ではこう書く（PyTorch）」、右に「この画面の中では（JavaScript・参考）」
- Python には**実行したときの出力をコメントで添える**（`# 0.693`）
- 画面の数字と、コードの出力が一致するようにする
- この画面が JavaScript で書かれている理由は README に書く。教材の中で言い訳しない

## 画面の名前は「学習者の行動」で付ける

システム側の分類語（詳細・設定・結果）ではなく、そこで何をするかを名前にする。
ナビのタブは短い名詞のままでよいが、**ページの中の見出しとリンクは動詞**にする。

| システムの言葉 | 使う言葉 |
|---|---|
| たとえ話ガイド | しくみを知る |
| 詳細 | 実験する |
| 学習開始 | この条件で学習する |
| リセット | 初期状態に戻す |
| 設定 | 実験の条件 |
| 結果 | 何が起きたか |
| 第0層の道具 | AIを理解する道具（設計資料では L0 / 第0層でよい） |
| ドリル（見出し） | 理解を確認する |
| 用語と記号（見出し） | 分からない言葉を調べる |

例外：**「学習」という語は言い換えない**。モデルが学習することそのものを教えているので、「実験を開始」に置き換えると学ぶべき用語が画面から消える。ボタンは「この条件で学習する」のように、学習という語を残したまま目的を足す。

## ボタンと操作の文言

| 用途 | 使う言葉 |
|---|---|
| 学習を進める | 学習する / 止める |
| やり直す | 最初から |
| 答え合わせ | 答え合わせ |
| 解説を開く | 途中式を見る |
| 次の問題 | 別の問題 |
| 予想を選ぶ | 動かす前に予想してみる |

「送信」「実行」「OK」のような、何が起きるか分からない言葉は使わない。
