# 設計と技術的な判断

AI Learning Lab を「どう作ったか、なぜそう作ったか」。プロダクトの説明は [README](../README.md) を見てください。

## なぜ JavaScript で書いてあるのか

実務で AI を書く言語は Python です。それでもこのアプリを素の JavaScript で書いているのは、**教材として次の3つを優先した**ためで、Python より良いからではありません。

1. **開いた瞬間に動く** — インストールも起動も要らない。学習の途中で環境構築に脱落させない
2. **触った瞬間に変わる** — 学習ループを毎フレーム回し、つまみを動かした結果をその場で返す（GAN で毎秒 300 ステップ前後）。サーバ越しでは、この即応性は出せない
3. **中身が全部見える** — ライブラリに隠れる部分がない。逆伝播も Adam も注意機構も、読めるコードとして置いてある

そのぶん、**教材の中に出てくるコードはすべて Python（PyTorch / numpy）を主**にしてあります。各ページの「コードで見る」では、実務で書く PyTorch を左に、同じ処理をこの画面の中で書いたものを右に並べています。

## 外部ライブラリを使わない

`npm install` が不要で、`public/` を静的配信するだけで動きます。学習用途では次の利点があります。

- 依存が腐らない。数年後に開いても動く
- 「ライブラリがやっていること」を教材として見せられる
- 配布が軽い。ファイルを開くだけでよい

代償として、行列演算は素の `Float64Array` で書いています。速度のために、活性化関数は分岐ではなく種別コードでインライン展開しています（`public/js/nn.js`）。

## サーバ側で計算しない・学習済みモデルを配らない

学習も推論もすべてブラウザの中で走ります。入力したテキストも、書いた自己説明も、外部には送信されません。進捗は `localStorage` にだけ保存します。
学習済みの重みも配布しません。**毎回その場で学習が起きること自体が教材**だからです。

## 題材を小さくする

2次元の点と、24 件の架空の社内規程。大きなデータを扱わないぶん、中身をすべて見せられます。

- GAN / VAE：2次元の点なら、分布・判定・勾配・潜在空間を1画面に並べられる
- 自己回帰：座標を 8 段階 × 4 トークンに量子化すると、8³ = 512 通りの接頭辞を全部流して確率表を作れる。近似ではなく厳密な p(x) を表示できる
- RAG：埋め込みモデルの代わりに文字 2-gram + TF-IDF。「なぜ言い換えに弱いのか」が説明できる形になる

2次元は自己回帰モデルに有利な舞台です（全 4096 マスを数え上げられる）。比較ページの優劣がそのまま高次元に当てはまるわけではない、と明記しています。

## 正しさの担保

逆伝播はすべて数値微分と突き合わせています（`npm test`）。

| モデル | 勾配チェックの最大誤差 |
|---|---|
| MLP（GAN） | 3.87e-11 |
| Transformer | 5.01e-10 |
| VAE | 7.65e-9 |

挙動そのものもテストしています。GAN が円周上の8つのガウスに収束すること、β を上げると事後崩壊が起きること（KL ≈ 0.008、σ ≈ 0.99）、RAG の検索が7つの想定質問で1位を当てること、資料にない質問では類似度が threshold を下回ること、MDS の地図で近傍が同じ規程グループになる割合が 55% 以上であること。

## 描画

Canvas 2D のみ。`devicePixelRatio` に合わせてバッキングストアを取り直し、色は CSS 変数から読むのでライト / ダークの切り替えに追従します。
色は、色覚特性のある人にも区別できる組み合わせを選んでいます。VAE の生成点のように、青と紫が隣り合う場面では**色ではなく形**（中抜きの丸）で区別しています。

## 実装メモ

**GAN**

- G: `z → [隠れ層 × depth, LeakyReLU] → x(2次元)`、D: `x → … → ロジット`
- Adam（β1 = 0.5, β2 = 0.999）。G は非飽和損失 `−log D(G(z))`（ミニマックス版も選べる）
- 勾配は D を通して G へ流すが、その際 D のパラメータは更新しない

**VAE**

- エンコーダ `x → (μ, logσ²)`、再パラメータ化 `z = μ + σ·ε`、デコーダ `z → x̂`
- 損失 `= 再構成誤差 / (2σₓ²) + β × KL(q(z|x) ‖ N(0, I))`、Adam（β1 = 0.9）
- p(x) の背景は、デコーダから z を 160 個引いた混合ガウスで近似

**自己回帰 Transformer**

- 入力 `[BOS, t₁, t₂, t₃]` → 予測 `[t₁, t₂, t₃, t₄]`（語彙 8・系列長 4）
- Pre-LN の `LayerNorm → 因果的マルチヘッド自己注意 → 残差 → LayerNorm → MLP → 残差`
- 損失は交差エントロピー（= 負の対数尤度）、Adam（β1 = 0.9, β2 = 0.99）

**RAG**

- 分かち書きの代わりに文字 2-gram（英数字は単語として保持）
- TF-IDF で重み付けし、コサイン類似度で検索。言い換えは小さな同義語表で代用
- 地図は類似度行列を二重中心化し、べき乗法で上位2成分を取る古典的 MDS

GAN・VAE・Transformer の逆伝播は、いずれも数値微分と一致することをテストで確認しています。
